# Privacy Policy

Last updated: 2026-10-09

This tool is a personal script used only by its owner to upload videos to the owner's own YouTube channel.

## What data it uses

- With the owner's permission, it uses Google OAuth to access the owner's YouTube account (upload videos, manage the owner's own videos, and read the owner's own channel analytics).
- The access token is stored only on the owner's own computer.

## What it does not do

- It does not collect, sell, or share any data with anyone.
- It does not access any other person's account.
- It does not send data to any server other than Google's APIs.

## Removing access

You can remove the tool's access at any time at https://myaccount.google.com/permissions.

## Use of Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
